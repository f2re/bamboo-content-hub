# Bamboo Content Hub — design guidelines

## Принцип
Интерфейс должен быть спокойным, очевидным и функциональным. Визуальное направление основано на принципах интерфейсов Apple: сильная иерархия, системная типографика, большие зоны нажатия, минимум визуального шума, progressive disclosure. Это не буквальная копия iOS/macOS.

## Иерархия
- На экране один главный CTA.
- Первичный контент важнее навигации и служебных статусов.
- Технические сущности (`delivery`, token scopes, webhook) не показываются без необходимости.
- Ошибка описывает, что произошло и что можно сделать дальше.

## Сетка и размеры
- Desktop: sidebar 230 px, содержимое до 1500 px.
- Mobile: основная навигация снизу.
- Touch target не меньше 44×44 CSS px.
- Основной radius: 22 px; поля/кнопки: 12–13 px.
- Контрольные viewport: 390×844, 768 px, 1280 px, 1440×900.

## Типографика
Системный стек `-apple-system, BlinkMacSystemFont, SF Pro Text, Segoe UI, sans-serif`. Заголовки используют отрицательный tracking только на крупных размерах. Текст интерфейса — по-русски, без инженерного жаргона.

## Цвет
Все цвета — через CSS variables. Поддерживаются светлая/тёмная системные темы. Информация не кодируется одним цветом.

## Движение
Анимация только для ориентации пользователя; `prefers-reduced-motion` обязателен.

## Формы
Не показывать 30 полей одновременно. Основной flow: базовая карточка → медиа → ИИ → публикация. Второстепенные характеристики раскрываются по запросу.

## Опасные действия
Отключение интеграции, удаление и разрушительные действия требуют явного подтверждения. Никогда не показывать токены полностью.

Справка

ИИ-контент

Открыл изделие → скопировал → вставил

Bamboo формирует полный рабочий запрос на лету: с request_id, текущими фактами, порядком медиа, правилами площадок и актуальной JSON Schema.

1

Получите готовый запрос

  1. Создайте изделие и заполните известные факты.
  2. Загрузите фото/видео в нужном порядке.
  3. Откройте «Подготовка с ИИ».
  4. Нажмите «Скопировать готовый запрос».

Ничего дописывать, подставлять или собирать вручную не нужно.

2

Передайте запрос модели

  1. Вставьте запрос как есть.
  2. Приложите те же файлы в порядке image_1…N.
  3. Скопируйте один JSON-объект без пояснений.
3

Проверьте результат

Вставьте JSON и нажмите «Проверить». Просмотрите needs_confirmation и assumptions. Цена, материалы, размеры, уход и наличие требуют явного подтверждения.

4

Примените и публикуйте

Hub заполнит только допустимые пустые поля и сохранит отдельные тексты для Instagram, VK, Telegram, Pinterest, Facebook, TikTok, YouTube и Ярмарки мастеров.

Статического промпта для копирования нет специально

Статический пример неизбежно устаревает и не содержит данных конкретного изделия. Источник истины один: Изделия → нужное изделие → Подготовка с ИИ → Скопировать готовый запрос.

Канонический генератор: app/ai_pack.py::build_prompt().

Перейти к изделиям
Подключения

Официальная ссылка → callback → подключить

Откройте нужную карточку. Технические поля скрыты, пока вы не выбрали сервис, поэтому страница остаётся компактной и понятной.

1

Создайте приложение

Нажмите официальную ссылку в карточке сервиса. Для Telegram достаточно открыть BotFather; для остальных площадок создайте Web/OAuth-приложение.

2

Скопируйте callback

Hub показывает точный Redirect URI. Скопируйте его без изменений, затем сохраните Client ID и Client Secret в интерфейсе.

3

Подключите аккаунт

Нажмите «Подключить аккаунт». Вход выполняется на официальной странице площадки; пароль от соцсети Bamboo не получает.

4

ID найдутся автоматически

Pinterest предложит доски, Meta — страницы и связанный Instagram Professional, VK — доступные стены и сообщества. Ручные ID остаются только запасным вариантом.

Обновление системы

Из каталога проекта запустите ./scripts/update.sh. Скрипт сам создаст резервную копию, загрузит актуальный main, пересоберёт контейнер, применит миграции, перезапустит Hub и выполнит smoke test.

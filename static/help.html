Справка

ИИ-контент

Один запрос — отдельный текст для каждой площадки

Bamboo Content Hub сам формирует рабочий промпт для конкретного изделия. Пользователь переносит его вместе с медиа в мультимодальную модель, проверяет JSON и импортирует результат без перезаписи уже введённых фактов.

1

Подготовьте изделие

  1. Создайте изделие и внесите известные характеристики.
  2. Загрузите фото/видео в нужном порядке.
  3. Откройте «Импорт из ИИ» в карточке изделия.
  4. Нажмите «Скопировать запрос».

Не меняйте request_id и не заменяйте рабочую JSON Schema примером из документации.

2

Получите JSON от модели

  1. Передайте модели скопированный запрос.
  2. Приложите те же медиа в том же порядке.
  3. Попросите выполнить запрос без дополнительных требований.
  4. Скопируйте один JSON-объект целиком.

Если модель не умеет анализировать конкретный тип медиа, она не должна додумывать его содержимое.

3

Сначала проверьте

  1. Вставьте JSON в поле ответа.
  2. Нажмите «Проверить».
  3. Просмотрите needs_confirmation и assumptions.
  4. Исправьте исходные факты или ответ, если модель что-то выдумала.
4

Импортируйте и публикуйте

  1. Нажмите «Импортировать».
  2. Хаб заполнит только пустые поля.
  3. Проверьте тексты каналов и выберите медиа.
  4. Выберите время и обязательные настройки площадки.

Приватность, согласия и коммерческие декларации TikTok выбирает человек перед отправкой.

Что создаётся для площадок

Instagram
caption, hashtags — живой пост и точные хэштеги.
VK
text, hashtags — более информативный самостоятельный текст.
Telegram
text, button_text, button_url — короткое сообщение; ссылка только реальная.
Pinterest
title, description, keywords, board_suggestion, destination_url.
Facebook
text — самостоятельный пост, не копия Instagram.
TikTok
caption, hashtags; privacy остаётся null и задаётся человеком.
YouTube
title, description, tags — только подтверждённое содержание.
Ярмарка мастеров
title, short_description, description, keywords, category_suggestion.

Что ИИ нельзя придумывать

Цена, материал, размеры, объём, масса, состав глазури, режим обжига, food-safe, ПММ, СВЧ, наличие, сроки, скидки, ссылки, доставка и любые другие не подтверждённые факты.

Неизвестное остаётся пустым и при необходимости попадает в needs_confirmation. Предположения — только в assumptions.

Какой должен быть стиль

Спокойный, тёплый, человеческий и предметный. Короткие абзацы, конкретные наблюдения, различающиеся версии для каналов.

Без канцелярита, давления, выдуманной срочности и штампов вроде «уникальный», «идеальный», «премиальный», если это не исходные данные.

Базовая часть промпта

Это только читаемая основа. Для реальной работы всегда копируйте запрос из карточки изделия: туда хаб подставляет request_id, факты, медиа, правила каналов и актуальную JSON Schema.

Где находится источник

Канонический генератор: app/ai_pack.py::build_prompt(). Подробная техническая инструкция в репозитории: docs/AI_IMPORT.md.

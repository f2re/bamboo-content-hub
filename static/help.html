ИИ-контент

Открыл изделие → скопировал → вставил

Bamboo формирует полный рабочий запрос на лету: с request_id, текущими фактами, порядком медиа, правилами площадок и актуальной JSON Schema.

1

Получите готовый запрос

  1. Создайте изделие и заполните известные факты.
  2. Загрузите фото/видео в нужном порядке.
  3. Откройте «Подготовка с ИИ».
  4. Нажмите «Скопировать готовый запрос».

Ничего дописывать, подставлять или собирать вручную не нужно.

2

Передайте запрос модели

  1. Вставьте запрос как есть.
  2. Приложите те же файлы в порядке image_1…N.
  3. Скопируйте один JSON-объект без пояснений.
3

Проверьте результат

Вставьте JSON и нажмите «Проверить». Просмотрите needs_confirmation и assumptions. Цена, материалы, размеры, уход и наличие требуют явного подтверждения.

4

Примените и публикуйте

Hub заполнит только допустимые пустые поля и сохранит отдельные тексты для Instagram, VK, Telegram, Pinterest, Facebook, TikTok, YouTube и площадки «Ярмарка мастеров».

Статического промпта для копирования нет специально

Источник истины один: Изделия → нужное изделие → Подготовка с ИИ → Скопировать готовый запрос.

Канонический генератор: app/ai_pack.py::build_prompt().

Перейти к изделиям
Публикация без приложений

Выбрал площадку → получил пакет → вставил

VK, Instagram, Facebook, Pinterest, TikTok и YouTube работают без n8n, developer app и браузерных cookies. Полная API-автоматизация остаётся дополнительным режимом.

1

Оставьте режим «Без приложения»

На странице «Подключения» он включён по умолчанию. Никакие callback URL, Client ID или Client Secret не требуются.

2

Создайте публикацию

В карточке изделия выберите площадки и медиа. Для TikTok и YouTube API-поля скрываются: параметры видимости и рекламы вы зададите в самой площадке.

3

Откройте готовый пакет

В разделе «Публикации» нажмите «Открыть пакет». Там есть кнопка копирования текста, отдельные файлы и ZIP со всеми материалами.

4

Опубликуйте штатно

Откройте площадку, вставьте текст, загрузите медиа и нажмите её обычную кнопку публикации. Затем отметьте результат в Bamboo.

Почему не cookies

Bamboo не копирует авторизационные cookies и не повторяет закрытые запросы веб-сайтов. Сессия остаётся в вашем браузере, а публикация выполняется через штатный интерфейс площадки.

Это устойчивее и безопаснее: нет хранения полноценной браузерной сессии и зависимости от внутренних endpoint сайта.

Когда нужен автоматический API

Только если требуется публикация полностью без участия человека. Откройте нужную карточку подключения и раскройте «Автоматически через официальный API — расширенный режим».

Telegram остаётся самым простым автоматическим каналом: BotFather → токен → @имя_канала.

Обновление системы

Из каталога проекта запустите ./scripts/update.sh. Скрипт создаст резервную копию, загрузит актуальный main, пересоберёт контейнер, применит миграции, перезапустит Hub и выполнит smoke test.

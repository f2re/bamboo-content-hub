Справка

ИИ-контент

Открыл изделие → скопировал → вставил

Рабочий промпт не хранится как пример, который надо редактировать вручную. Bamboo Content Hub формирует полный запрос на лету для конкретного изделия: с request_id, текущими фактами, порядком медиа, правилами всех площадок и актуальной JSON Schema.

1

Получите готовый запрос

  1. Создайте изделие и внесите известные характеристики.
  2. Загрузите фото/видео в нужном порядке.
  3. Откройте «Импорт из ИИ» в карточке изделия.
  4. Проверьте подписи image_1…N рядом с медиа.
  5. Нажмите «Скопировать готовый запрос».

Ничего дописывать, подставлять или заменять в запросе не надо. Если карточка изменилась, нажмите «Обновить из карточки» — страница сформирует запрос заново.

2

Вставьте его в модель

  1. Вставьте запрос как есть.
  2. Приложите те же медиа в том же порядке.
  3. Не добавляйте отдельные требования к формату ответа.
  4. Скопируйте один JSON-объект целиком.

Если модель не умеет анализировать конкретный тип медиа, она должна оставить связанные данные пустыми, а не додумывать содержимое.

3

Сначала проверьте

  1. Вставьте JSON в поле ответа.
  2. Нажмите «Проверить».
  3. Просмотрите needs_confirmation и assumptions.
  4. Если всё корректно, нажмите «Импортировать».
4

Публикуйте

  1. Хаб заполнит только пустые поля изделия.
  2. Для площадок сохранятся отдельные тексты.
  3. Выберите медиа, канал и время.
  4. Заполните обязательные настройки самой площадки.

Приватность, согласия и коммерческие декларации TikTok выбирает человек перед отправкой.

Что создаётся для площадок

Instagram
caption, hashtags — самостоятельный пост и точные хэштеги.
VK
text, hashtags — более информативный самостоятельный текст.
Telegram
text, button_text, button_url — короткое сообщение; кнопка только при реальной ссылке.
Pinterest
title, description, keywords, board_suggestion, destination_url.
Facebook
text — самостоятельный пост, не копия Instagram/VK.
TikTok
caption, hashtags; privacy остаётся null и задаётся человеком.
YouTube
title, description, tags — только подтверждённое содержание.
Ярмарка мастеров
title, short_description, description, keywords, category_suggestion.

Что ИИ нельзя придумывать

Цена, материал, размеры, объём, масса, состав глазури, режим обжига, food-safe, ПММ, СВЧ, наличие, сроки, скидки, ссылки, доставка и любые другие не подтверждённые факты.

Неизвестное остаётся пустым и при необходимости попадает в needs_confirmation. Предположения — только в assumptions.

Какой должен быть стиль

Спокойный, тёплый, человеческий и предметный. Короткие абзацы, конкретные наблюдения, различающиеся версии для каналов.

Без канцелярита, давления, выдуманной срочности и рекламных штампов.

Статического промпта для копирования нет специально

Пример из документации неизбежно устаревает и не содержит данных конкретного изделия. Поэтому пользовательский источник истины один: Изделия → нужное изделие → Импорт из ИИ → Скопировать готовый запрос.

Канонический генератор находится в app/ai_pack.py::build_prompt(). При открытии страницы он подставляет текущий request_id, факты изделия, количество и порядок медиа, требования площадок и JSON Schema из установленной версии приложения.

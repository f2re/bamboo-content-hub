# Импорт из ИИ

Хаб генерирует `request_id`, обозначает локальные изображения как `image_1...N` и формирует prompt вместе с JSON Schema `bamboo-content-pack/1.0`. Пользователь переносит prompt и фото в любую мультимодальную модель, затем вставляет один JSON обратно.

Импорт: extraction → `json.loads` → Pydantic → domain rules → `request_id` → merge. `eval` не используется. Текущие человеческие значения имеют приоритет; ИИ заполняет пустые поля. Неизвестные факты должны оставаться `null` и попадать в `needs_confirmation`.

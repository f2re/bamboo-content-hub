# Подключения соцсетей

Перед production-подключением сверяйте scopes, review и audit-требования с текущей официальной документацией провайдера. Секреты и OAuth-токены хранятся в зашифрованном виде; в журнал и интерфейс они не выводятся.

## Матрица адаптеров

| Канал | Режим | Медиа | Проверка подключения | Состояние после отправки |
|---|---|---|---|---|
| Telegram | автоматический | текст, фото, видео, группы до 10 файлов | `getMe` | опубликовано сразу |
| VK | автоматический | текст, фото | профиль/доступ API | опубликовано сразу |
| Pinterest | автоматический | одно изображение | профиль/доска | опубликовано сразу |
| Instagram | автоматический | фото, карусель, видео | Meta Graph API | опрос контейнера до готовности |
| Facebook | автоматический | текст, фото, видео | Meta Graph API | опубликовано сразу |
| TikTok | Direct Post | одно видео либо до 35 фото | свежий `creator_info` | опрос `publish/status/fetch` |
| YouTube | resumable upload | одно видео | `channels.list(mine=true)` | опрос обработки видео |
| Ярмарка мастеров | ручной экспорт | по инструкции | не требуется | подтверждает пользователь |

Экран «Подключения» позволяет сохранить обязательные ID страницы, стены или доски и выполнить отдельную проверку каждого канала. Проверка не создаёт публикацию.

## Telegram

Создайте бота через BotFather, добавьте его администратором канала и в «Подключения» укажите токен бота и chat ID/`@channel`. Пустое поле токена при повторном сохранении не удаляет уже сохранённый секрет.

## Google / YouTube

1. Создайте OAuth Web Application в Google Cloud.
2. Включите YouTube Data API.
3. Зарегистрируйте callback `https://<ваш-host>/oauth/google/callback`.
4. Подключите аккаунт на странице «Подключения».
5. При необходимости сохраните числовой ID категории YouTube; по умолчанию используется `22`.

Хаб запрашивает offline access, сохраняет refresh token зашифрованно и перед каждой публикацией требует от пользователя заголовок, описание и видимость. Видео отправляется частями через resumable upload. При кратковременной сетевой или серверной ошибке адаптер запрашивает подтверждённый диапазон и продолжает с последнего принятого байта. После загрузки доставка остаётся в состоянии обработки до ответа YouTube `processed`/`succeeded`.

Непроверенный OAuth-проект Google может принудительно оставлять загруженные видео приватными до прохождения аудита проекта.

## Pinterest

Создайте приложение Pinterest Developer и callback `/oauth/pinterest/callback`. Нужны scopes чтения досок и создания Pins. После OAuth сохраните ID доски и, при необходимости, ID раздела. Production-возможности зависят от уровня доступа приложения.

## TikTok

1. Создайте TikTok developer app, подключите Login Kit и Content Posting API.
2. Зарегистрируйте callback `/oauth/tiktok/callback`.
3. Получите разрешение `video.publish` и подключите аккаунт.
4. Для публикации фото подтвердите в кабинете TikTok домен или URL-префикс, с которого хаб отдаёт signed media URL. `APP_BASE_URL` должен быть публичным HTTPS-адресом этого домена.
5. Перед каждой публикацией хаб повторно вызывает `creator_info`, показывает аккаунт, доступные варианты видимости и ограничения взаимодействий.
6. Пользователь редактирует подпись, выбирает видимость, декларацию коммерческого контента и явно подтверждает отправку.

Видео отправляется частями с `Content-Range`; фото передаются списком публичных URL. Адаптер не допускает смешанную публикацию фото и видео, локальные/HTTP URL фото, платное партнёрство с видимостью `SELF_ONLY` и отправку без явного согласия. После инициализации хаб опрашивает статус до завершения или ошибки.

До прохождения TikTok audit Direct Post обычно ограничен видимостью `SELF_ONLY`, лимитами тестовых пользователей и публикаций. Эти ограничения задаёт TikTok, а не Bamboo Content Hub.

## Meta / Instagram / Facebook

Создайте Meta app и настройте разрешённый callback `/oauth/meta/callback`. В «Подключения» укажите Instagram Professional ID и/или Facebook Page ID. Для Instagram publishing нужны публично доступные HTTPS media URL — хаб генерирует краткоживущие signed URL.

## VK

Создайте приложение VK ID и зарегистрируйте `/oauth/vk/callback`. После OAuth укажите ID стены: положительный ID пользователя либо отрицательный ID сообщества. Endpoints вынесены в `.env`, чтобы обновлять OAuth-профиль независимо от ядра.

## Ярмарка мастеров

Используется контролируемый ручной экспорт. Скрытые undocumented endpoints сайта не используются.

## Проверка перед production

CI проверяет контракт адаптеров через `httpx.MockTransport`: валидацию, payload, классификацию ошибок, загрузку частей, восстановление YouTube, health и polling. Реальная отправка во внешние аккаунты намеренно не выполняется в CI, поскольку требует пользовательских токенов, подтверждённых доменов и audit/review приложения.

Перед вводом в эксплуатацию для каждого подключённого аккаунта:

1. Нажмите «Проверить» на странице «Подключения».
2. Создайте приватную тестовую публикацию с одним небольшим медиафайлом.
3. Убедитесь, что доставка переходит `pending → processing → published`.
4. Проверьте результат в приложении провайдера и только затем включайте расписание.

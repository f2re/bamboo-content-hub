# Bamboo Content Hub

Локальный контент-центр Bamboo Pottery: изделие и медиа создаются один раз, ИИ возвращает структурированный `Bamboo Content Pack`, а Hub готовит отдельные тексты и публикационные задания для соцсетей.

## Что уже работает

- каталог изделий, ручной редактор характеристик и текстов площадок;
- загрузка и оптимизация фото/видео, порядок медиа, обложка и удаление;
- `bamboo-content-pack/1.0`: полный runtime prompt → preview/import → безопасное merge;
- отдельный контент для Instagram, VK, Telegram, Pinterest, Facebook, TikTok, YouTube и Ярмарки мастеров;
- черновики, расписание, независимые доставки, retries и idempotency;
- **режим без developer app**: Bamboo собирает готовый текст, выбранные медиа, ZIP и ссылку открытия площадки;
- автоматический Telegram через BotFather;
- опциональные официальные API-адаптеры VK, Pinterest, Instagram, Facebook, TikTok и YouTube;
- OAuth state/PKCE/exchange/refresh/revoke и зашифрованное хранение токенов;
- signed public media URL, webhook storage и проверка Meta signature;
- светлый адаптивный PWA-интерфейс;
- SQLite WAL, Alembic, Docker Compose, backup/restore/update.

## Быстрый старт

```bash
git clone https://github.com/f2re/bamboo-content-hub.git
cd bamboo-content-hub
./scripts/install.sh
```

Откройте `http://localhost:8080`.

## ИИ: готовый запрос без ручной сборки

Рабочий промпт **не надо брать из README, править или собирать по частям**. Он формируется на лету для конкретного изделия на странице **Изделия → нужное изделие → Подготовка с ИИ** (`/products/{id}/ai`).

Bamboo автоматически подставляет:

- текущий `request_id`;
- известные факты изделия;
- количество и порядок фото/видео (`image_1...N`);
- редакционные правила Bamboo Pottery;
- отдельные требования площадок;
- полный контракт ответа;
- актуальную JSON Schema `bamboo-content-pack/1.0`.

Порядок работы:

1. Нажмите **«Скопировать готовый запрос»**.
2. Вставьте его в мультимодальную модель и приложите показанные медиа в том же порядке.
3. Скопируйте один JSON-ответ обратно в Hub, нажмите **«Проверить»**, затем **«Импортировать»**.

ИИ не должен придумывать цену, материалы, размеры, объём, массу, глазурь, режим обжига, пищевую безопасность, ПММ/СВЧ, наличие, сроки, скидки, ссылки или доставку. Новые критичные факты не записываются без явного подтверждения человека.

Полная инструкция: [docs/AI_IMPORT.md](docs/AI_IMPORT.md).

## Публикация без регистрации приложений

Для VK, Instagram, Facebook, Pinterest, TikTok и YouTube режим **«Без приложения»** включён по умолчанию. n8n, Client ID, callback URL, OAuth и браузерные cookies для этого не нужны.

Порядок:

1. В карточке изделия выберите площадки и медиа.
2. Нажмите **«Опубликовать»**.
3. Откройте раздел **«Публикации»** и нажмите **«Открыть пакет»**.
4. Скопируйте готовый текст, скачайте все материалы одним ZIP либо по отдельности.
5. Откройте площадку штатной кнопкой, вставьте текст и загрузите медиа.
6. После публикации отметьте пакет как опубликованный; при желании сохраните ссылку на пост.

Bamboo не копирует браузерную сессию, не хранит cookies и не вызывает закрытые внутренние endpoints сайтов. Вход остаётся в обычном браузере, а окончательное действие выполняется через официальный интерфейс площадки.

### Ограничения ручного пакета

Bamboo подготавливает данные, но параметры, зависящие от текущего аккаунта, выбираются на самой площадке: видимость, музыка, рекламные декларации, доска Pinterest, страница/сообщество и другие динамические настройки.

## Автоматическая публикация — дополнительный режим

Полностью автоматическая отправка через официальный API остаётся доступной. На странице **«Подключения»** раскройте нужную площадку и выберите **«Автоматически через официальный API — расширенный режим»**.

Для API-режима могут потребоваться:

- developer app;
- HTTPS callback;
- Client ID/Secret;
- OAuth;
- review/audit приложения;
- подтверждённый домен и специальные права аккаунта.

Существующие OAuth-подключения не ломаются: если ранее были сохранены токены или реквизиты приложения, Bamboo сохраняет автоматический режим. В любой момент можно переключиться на пакет без приложения, не удаляя OAuth-реквизиты.

Telegram подключается проще остальных: **BotFather → токен → `@имя_канала` → проверить**.

Подробности: [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md).

## Обновление

```bash
./scripts/update.sh
```

Updater создаёт резервную копию, загружает актуальный `main`, пересобирает контейнер, применяет миграции, перезапускает Hub и выполняет smoke test. Пользовательские изменения не сбрасываются автоматически.

## Разработка

```bash
python -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
alembic upgrade head
uvicorn app.main:app --reload --port 8080
pytest
```

## Принцип интеграций

Основной пользовательский путь не должен зависеть от скрытых API, браузерных cookies или n8n. Официальные API используются только там, где пользователь сознательно выбирает полную автоматизацию и выполняет требования площадки.
